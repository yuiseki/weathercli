# @yuiseki/weathercli

Weather CLI for current conditions and 3-day forecast using Open-Meteo.

## Install

```bash
npm i -g @yuiseki/weathercli
```

Installed commands:

- `weather` (recommended)
- `weathercli` (compatibility alias)

## Usage

```bash
weather --help
```

### Main commands

- `weather` / `weather list` / `weather ls`: show current weather and 3-day forecast
- `weather sync`: bypass cache and refresh snapshot immediately (today only)

### Date and history

- Default target date is today.
- `--date <yyyy-mm-dd>` reads/writes a specific date snapshot.
- Past dates are cache-only. `weather` does not call Open-Meteo for past dates.

Examples:

```bash
weather --date 2026-02-20 --city tokyo
weather --date 2026-02-20 --lat 35.7126 --lon 139.7799
weather --date 2026-02-21 --sync
```

### Location selection

- Default: detect current location by IP
- Preset cities: `tokyo`, `osaka`, `nagoya`, `sapporo`, `fukuoka`
- Coordinates: `--lat <number> --lon <number>`

### Options

- `--sync`: force refresh when using `weather list` (today only)
- `-d, --date <yyyy-mm-dd>`: target date (default: today)
- `-c, --city <name>`: preset city name
- `--tokyo`, `--osaka`, `--nagoya`, `--sapporo`, `--fukuoka`: preset shortcuts
- `--lat <number>` and `--lon <number>`: coordinate query
- `-j, --json`: JSON output
- `--cache-dir <path>`: override cache directory
- `--cache-ttl-minutes <minutes>`: cache TTL (default: `30`)

## Cache

Default cache directory:

- `$XDG_CACHE_HOME/weathercli` if `XDG_CACHE_HOME` is set
- `~/.cache/weathercli` otherwise

Cache file layout:

- `<cache-root>/YYYY/MM/DD/<country>/<state>/<locality>/data.json`
- Example:
  - `~/.cache/weathercli/2026/02/21/japan/tokyo/taito/data.json`

Location hierarchy is generated by reverse geocoding with `https://nominatim.yuiseki.net`.
